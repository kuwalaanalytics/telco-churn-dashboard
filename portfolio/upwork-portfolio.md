# Upwork Portfolio Entry

## Project title

Customer Churn Analysis, Prediction Model and Interactive Dashboard for a Telecom Business

## Project description (150 words)

This project shows how I help subscription businesses find out who is leaving, why, and what to do about it.

Using the public IBM Telco sample dataset (7,043 customers), I cleaned the data, analysed churn across contracts, tenure, payment methods and services, and built five customer segments. The analysis found a 26.5% churn rate costing $139,131 in monthly revenue, with month-to-month customers leaving at 42.7% against 2.8% on two year contracts.

I then built a churn prediction model (78% recall, 0.84 ROC-AUC) that scores every customer's risk. The riskiest 20% of customers contained 51% of all leavers, giving a retention team a focused call list.

The deliverable is a single interactive dashboard with filters, KPI cards, a sortable at-risk customer table and six retention recommendations. It works offline, on laptop and phone.

This is a demonstration on public sample data, not a client project.
